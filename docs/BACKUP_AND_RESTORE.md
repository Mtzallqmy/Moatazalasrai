# النسخ الاحتياطي والاستعادة

- استخدم backup PostgreSQL مشفرًا ومقيد الوصول، مع retention يقرره المنتج والالتزامات القانونية. الأسرار داخل DB مشفرة، لكن backup يظل حساسًا.
- قبل كل migration: سجل timestamp وschema version وbackup ID وتحقق من اكتماله.
- اختبار restore يتم إلى قاعدة معزولة لا تقبل traffic ولا تستخدم مفاتيح إنتاج إلا من secret manager المخصص للاختبار.

## اختبار الاستعادة

1. أنشئ قاعدة معزولة وشبكة وصول مقيدة.
2. استعد النسخة، ثم شغّل فحص الجداول والقيود وعدد السجلات المرجعي.
3. شغّل migrations المطلوبة و`npm run test:integration` باستخدام `TEST_DATABASE_URL` المعزول.
4. تحقق من tenant isolation وعينة decrypt مخولة دون طباعة plaintext.
5. أتلف البيئة المؤقتة وفق سياسة المؤسسة وسجل RPO/RTO الفعليين.

النسخ لا تعني امتثالًا قانونيًا تلقائيًا. حذف المستخدم/المؤسسة يجب أن يراعي retention والنسخ غير القابلة للتعديل وفق قرار منتج/قانوني موثق.
