# المزودات والنماذج

المزودات الحالية: OpenAI وAnthropic وGemini وأي endpoint موثق OpenAI-compatible يملكه المستخدم. يمكن ربط OpenRouter وGroq وOllama وLocalAI وvLLM وLiteLLM عبر OpenAI-compatible عند توافق API.

قد تتوفر حصة مجانية حسب المزود والحساب والمنطقة؛ لا تضمن المنصة مجانية أي خدمة. مصدر الحقيقة هو صفحة التسعير والحدود الرسمية للمزود وقت الإعداد.

كل اتصال يمر بالتحقق من URL وDNS والعناوين الخاصة وTLS وبيانات الاعتماد واكتشاف النماذج واختبار نموذج قبل الحفظ المشفر. تعطل مزود اختياري لا يعطل بقية المنصة.
