# مكتبة الوكلاء

تتضمن المنصة قوالب أصلية قابلة للإنشاء والنشر من صفحة الوكلاء. لا تنسخ هذه
القوالب كودًا أو prompts خاصة من منتجات أخرى؛ بل تطبق أنماطًا عامة مثل:

- التخطيط والتنفيذ والتحقق من النتيجة.
- بناء التطبيقات من المتطلبات حتى الاختبار.
- البحث المعتمد على المصادر.
- هندسة البرمجيات ومراجعة GitHub.
- تحليل البيانات والمستندات.
- تنسيق العمليات والمحافظة على الهدف.

استُلهمت مبادئ تجربة الاستخدام من المصادر الرسمية لـ
[Manus](https://manus.im/)،
[Manus Skills](https://manus.im/docs/features/skills)،
[Emergent](https://help.emergent.sh/)،
و[OpenHands](https://github.com/All-Hands-AI/OpenHands).

كل وكيل يُنشأ فعليًا داخل المؤسسة، ويرتبط بمزود متحقق ونموذج مكتشف، ويحصل
على إصدار immutable وسجل تدقيق. القوالب لا تمنح أدوات أو صلاحيات؛ الأدوات
تبقى خاضعة لقائمة السماح وRBAC والموافقة على العمليات الحساسة.
